# QR Studio

A clean, fast, and multilingual QR code generator built with Next.js and React.

## Features

- Generate QR codes from URLs and text
- Download QR codes as PNG
- Copy entered content
- English, فارسی, and پښتو
- Automatic RTL/LTR support
- Light and dark mode
- Responsive design
- Client-side QR generation
- No content uploaded or stored

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- QRCode
- next-themes
